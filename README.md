Blog_project

Это небольшой проект который я создал путем использования языка Python и HTML файлов.
Собой он представляет простенький аналог сайта для выкладывания блогов со своей регистрацией, гостевым режимом и с особыми возможностями для админов

Возможности:
1. Выкладывание блогов с возможностью добавления файлов. И редактированием с возможностью удаления юлогов
2. Просмотр в гостевом режиме
3. Добавление комментариев с возможностью удаления того кто это написал или человека обладающим админкой

Для локального запуска:

1. Перекачать файл
2. Установить модель Django командой pip instull django
3. Прописать команду py manage.py runserver( если среда активирована если нет то пропишите myenv\Scripts\activate )
